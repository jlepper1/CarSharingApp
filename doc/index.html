Familien-Carsharing

A web app for a family that shares cars: reserve a car, record the kilometres driven, enter the costs and settle up fairly. It runs on iPhone and Android as an app on the home screen (PWA), without an app store.

This documentation describes version 1.5.3. The app itself is in German; this documentation is in English, and every button or screen name is quoted exactly as it appears in the app, for example „Mehr → Autos“.

Contents

Features What the app can do: calendar, trips, costs, settlement, export, sharing rules. User guide Step-by-step instructions for family members using the app every day. Installation Set the app up on a new computer, build it and publish it on GitHub Pages. Database setup Manual first start of a new database: schema, user accounts, passwords, cars. Architecture Programming language, servers, hosting, and how the app uses the database.

At a glance

UsersA family (designed for about five people) sharing one or more cars
ClientSingle-page web app / Progressive Web App, German user interface
LanguageTypeScript (React 19), styled with Tailwind CSS, built with Vite
HostingStatic files on GitHub Pages, deployed automatically on every push to main
BackendSupabase: PostgreSQL database, authentication, REST API, realtime, file storage
AccountsCreated by hand in the Supabase dashboard; no self-registration

Typical first-time path

  1. Create the database and the user accounts (administrator, once).
  2. Install, build and publish the app (administrator, once).
  3. Every family member installs the app on their phone and signs in — see the user guide.
